# Pizza-Sales-Analysis-DashBoard
Developed an interactive Power BI dashboard to analyze pizza sales, orders, profit, customer behavior, product performance, and payment trends. Used Power Query for data preparation and DAX measures for business calculations, with interactive cards, charts, and slicers to provide actionable sales insights.
